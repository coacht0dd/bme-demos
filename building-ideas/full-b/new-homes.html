Do you build custom homes on my lot?

Yes. We build custom homes across North Metro Atlanta. If you already have a lot, we start with feasibility and budget so you know what makes sense before you commit. Call or text 404-771-9004.

What is an infill home?

An infill home is a new house built on an empty or teardown lot inside an established neighborhood. It lets you live where you want in a brand-new home. We can help you check whether a lot works.

Do you build for investors?

Yes. We build investor-owned and spec homes with written budgets and builder discipline, because thin margins can’t absorb surprises. See our Residential Development page or call us.
